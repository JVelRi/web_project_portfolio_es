Portafolio Personal – Juan Manuel Velasquez Rivera
Descripción
Portafolio personal desarrollado como proyecto formativo del bootcamp de desarrollo web Full Stack en Tripleten. El sitio presenta información profesional, habilidades técnicas y proyectos destacados, con un diseño moderno de tema oscuro y elementos decorativos con efectos de iluminación.
El portafolio incluye las siguientes secciones:

Hero — Presentación personal con foto de perfil, descripción, subtítulo profesional y enlaces de acción.
Habilidades y herramientas — Iconografía de las tecnologías dominadas.
Proyectos destacados — Tarjetas con imagen, descripción, stack tecnológico y enlaces a demo en vivo y repositorio.
Contacto — Correo electrónico y redes sociales.

Tecnologías y técnicas utilizadas

HTML5 — Estructura semántica con etiquetas como <section>, <nav>, <ul> y atributos de accesibilidad (aria-label, alt).
CSS3 — Estilos personalizados sin frameworks, organizados en archivos separados (fonts.css, index.css).

Variables CSS con :root para tokens de diseño (colores, tipografía).
Layout con CSS Grid y Flexbox.
Pseudo-elementos ::after para decoradores visuales.
Efectos de iluminación con filter: blur() y radial-gradient.
Diseño responsivo con Media Queries para tres breakpoints: escritorio (>1023px), tableta (≤1023px) y móvil (≤767px).

Google Fonts — Tipografías Archivo Black y Open Sans.
Git & GitHub — Control de versiones y publicación mediante GitHub Pages.
